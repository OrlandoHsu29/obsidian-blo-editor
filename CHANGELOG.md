# Changelog

## 0.1.2 — 2026-10-17

- Rename the plugin to Blo Editor, from block.
- Preserve the existing plugin ID, settings, and hotkey bindings.

## 0.1.1 — 2026-10-17

- Restore the block menu on left click while preserving whole-block selection.
- Delete blocks and their children from the block menu, with undo support.
- Keep Tab and Shift+Tab indentation available while the block menu is open.
- Share menu behavior between left and right click; clean up listeners on close.
- Use InkNote Editor as the plugin's English display name.
- Add reproducible packaging, build automation, and contribution guidance.

## 0.1.0

- Establish the customized rich-text editor based on Wysimark Editor 1.3.2.
- Include block editing, theme-aware formatting, tables, code highlighting,
  document search, native outline integration, and Markdown persistence.
