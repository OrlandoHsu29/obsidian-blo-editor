# Blo Editor v0.1.0 · 块编辑 / Block Editing

遵循语雀编辑习惯的 Obsidian 块编辑器。Blo 取自 block，基于 Wysimark Editor 二次开发，底层使用 Slate。

A Yuque-inspired block editor for Obsidian. Blo comes from block, built on Wysimark Editor and Slate.

## 功能 / Features

- 块拖动、父子缩进与整块选择、删除。 / Drag, indent, select, and delete blocks with their children.
- 富文本样式、主题自适应颜色、列表与引用。 / Rich-text formatting, theme-aware colors, lists, and quotes.
- 表格、代码高亮、图片插入与缩放。 / Tables, code highlighting, and image insertion and resizing.
- 查找替换、斜杠菜单与原生大纲导航。 / Find and replace, slash commands, and native outline navigation.
- Markdown 保存，自动保存编辑内容。 / Markdown storage with automatic saving.

## 安装 / Installation

下载 `blo-editor-0.1.0.zip`，解压后将 `blo-editor` 文件夹放入笔记库的 `.obsidian/plugins/`，重启 Obsidian 并启用 **Blo Editor**。

Download `blo-editor-0.1.0.zip`, extract the `blo-editor` folder into your vault's `.obsidian/plugins/`, restart Obsidian, and enable **Blo Editor**.

需要桌面版 Obsidian 1.8.7 或更新版本。基于原生 CodeMirror 的编辑插件需要单独适配。

Requires desktop Obsidian 1.8.7 or later. CodeMirror-based editing extensions require separate integration.
