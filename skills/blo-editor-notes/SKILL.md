# Blo Editor 笔记

交付能被 Blo Editor 继续编辑的笔记及所需附件。Blo 基于 Slate；文件格式是 Markdown 加 `wysimark-block:v1`、`wysimark-table:v1` 元数据，不能把扩展注释当垃圾清理，也不能把复杂块层级替换成视觉相似的普通 Markdown。

## 开始工作

- 确定目标知识库和笔记路径。使用用户提供的路径或当前工作区；不要猜测机器上的其他知识库。仅检查目标笔记、相邻风格样例和必要配置，不遍历私人笔记。
- 若能读取本地文件，检查目标库 `.obsidian/plugins/blo-editor/data.json` 的 `attachmentFolder`、`enableDrawings`、`richEditingFolder`。配置目录可能被用户改名，应使用用户给出的插件目录定位。附件路径缺省为 `附件`，空字符串表示库根；更改路径不会迁移旧附件。
- 创建或改动块、颜色、表格前读 [格式协议](references/format.md)。需要画板时再读 [画板与附件](references/drawings.md)。[完整示例](assets/example-note.md) 可复制调整；同时复制它引用的 [示例画板](assets/example.excalidraw.md)，或按任务生成真实场景。

## 编写与修改

可以按内容需要自由组合下列能力，不必等用户逐项要求“插入表格”“添加引用”才使用。用户指定某种结构时优先满足；未指定时选择最适合表达内容的块。遵循用户现有的语言、结构与编号风格，不为展示功能而强行使用所有样式。

| 可用内容能力 | 写笔记时如何选用 |
| --- | --- |
| 正文、H1～H4、H5 子标题 | 组织讲解与章节；标题层级和块缩进各司其职 |
| 有序、无序、任务列表 | 表达步骤、并列要点、可勾选行动；支持父子块与适用的折叠、编号 |
| 表格 | 比较方案、参数、术语、状态和结构化数据；可设列对齐、标题行/列，单元格中组合样式、链接和行内公式 |
| 引用与 Callout | 区分引用原文、提示、注意事项和补充说明；保留来源，别把自己编写的解释冒充外部引文 |
| 围栏代码块与行内代码 | 成段代码、配置、命令使用带语言的代码块；变量、函数名、短命令使用行内代码 |
| 行内公式与独立公式块 | 句中符号和短公式用行内 LaTeX；需要独立展示的推导或公式用块公式 |
| 链接与脚注 | 添加外部资料、库内笔记/标题跳转、显示文字和来源注释 |
| 加粗、斜体、下划线、删除线、颜色 | 强调关键内容或标记修订；默认正文随主题变色，强调色使用固定色板 |
| 分割线 | 分隔明显不同的内容区段，不用大量空行模拟排版 |
| 图片、音视频、PDF 及文件附件 | 直接引用已有文件，或先保存真实附件再嵌入；保留路径、描述及适用的预览尺寸 |
| 可编辑 Excalidraw 画板 | 表达流程、关系、架构或空间布局；交付真实画板文件及笔记中的嵌入引用 |
| 块缩进、父子关系、折叠与标题编号 | 组织跨类型内容；表格、引用、代码和媒体也能成为正文或列表父块下的子块 |

这些是可生成的笔记内容能力，不代表存在同名 MCP 工具或可直接调用的 API。按后文可用工具选择实现方式：能写文件就按协议生成内容块，已有可靠编辑器接口时也可使用接口；无需模拟点击工具栏。创建上述内容前读取[格式协议](references/format.md)，画板与媒体附件另见[画板与附件](references/drawings.md)。

- H1～H4 进入大纲，H5 是不进大纲的子标题。所有标题固定在块深度 0；用标题级别表达章节关系，用块 depth 表达正文父子关系。
- 正文、列表、引用、表格、代码及媒体都能成为子块。移动、重写父块时保留其后连续更深的子块，并保留相对深度。
- 样式使用可解析的行内标记和有限色板，默认正文随主题变色。不要注入字体、间距、定位 CSS 或编辑器占位符。
- 画板是独立可编辑的 Excalidraw 附件加 `![[...]]` 引用。只有 Mermaid、PNG 或空文件不能满足用户要求的可编辑画板。
- 已有笔记仅修改任务涉及的内容，保留未知元数据、frontmatter、链接、块 ID、公式和附件路径。不要用 Markdown 导出功能回写原文件；导出会简化私有格式。

## 根据可用工具交付

**有编辑器控制工具**：先确认工具确实支持当前 Blo/Slate 视图。用插件命令或 Slate 操作修改，保留选区与撤销；原生 CodeMirror 工具不一定适用。禁止直接改 DOM 伪造内容。

**有文件读写工具**：可以直接生成符合协议的 `.md` 和附件。修改前重读原文件；若笔记或画板正在编辑，先让可用的保存接口完成保存，或请用户保存并关闭目标标签。写入前确认源文件未变；发现并发修改先重新读取合并。文件写入不会进入 Slate 撤销历史。不要覆盖未保存内容，也不要通过重载整个插件强制解决冲突。

**只能聊天**：提供可下载文件（平台支持时），或完整文件内容与库内相对路径。说明尚未写入知识库；没有文件能力时不能承诺自动安装或自动创建附件。不要声称生成文本就已在 Obsidian 中使用成功。

## 完成检查

检查每个块标记可 `decodeURIComponent` 后解析为 JSON；块深度、标题位置和父子边界合理；表格标记紧邻对应表格；围栏闭合，代码中的注释未被改写；所有新附件引用指向真实文件且不重名覆盖。画板 JSON 中 ID 唯一、文字和形状完整，引用关系匹配。

有 Blo 环境时打开结果检查缩进、标题编号、大纲、表格、样式和画板预览，保存后重开确认。没有运行环境时说明只做了文件级检查。交付时列出实际创建或修改的笔记与附件，说明验证范围。

此 Skill 教会 AI 文件协议与操作方法，不授予知识库访问权限，也不自动安装 Excalidraw 或其他插件。安装位置由 AI 客户端的 Skill 机制决定；复制整个 `blo-editor-notes` 目录，保留 references 和 assets。插件更新后，可从设置页重新复制安装提示词更新此 Skill。
