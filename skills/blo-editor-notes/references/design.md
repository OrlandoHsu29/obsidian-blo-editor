# 视觉与排版指南

## 从基础稿到可长期维护的笔记

先把内容组织清楚，再挑出视觉层级、归属关系或后续编辑方式确实需要改变的地方。通常只需读这份指南的一张表，随后用[格式协议](format.md)核对目标样式。写普通 Markdown 草稿时可直接参考[基础稿](../assets/example-draft.md)。

| 信息用途 | 在 Blo 中的样子 | 何时选用 |
| --- | --- | --- |
| 正文与章节 | 正文跟随主题字色。H1～H4 随级别区分字号和间距，并同步进大纲。H5 是带较大垂直间距的局部小标题 | H1～H4 用来导航。短小的「例子」「验证方法」可用 H5，避免把大纲塞满 |
| 多级标题编号 | 标题前显示计算出来的章节号，大纲同步显示。正文有序列表单独计数 | 手册、规范、流程文档需要引用“第 2.1 节”时启用。日常笔记用普通标题即可 |
| 无序、有序、任务列表 | 圆点、数字或可切换的复选框。缩进层级可显示左侧引导线 | 圆点用于并列事实，数字用于有顺序的操作，复选框用于可验收的行动 |
| 真实父子块与折叠 | 子块向右缩进。折叠箭头出现于有子块的有序或无序父项旁；移动父项带上子块 | 一个步骤的说明、证据表和命令要成组。只有辅助说明适合默认折叠，关键限制留在外面 |
| 普通引用和提示框 | 普通引用从左侧引线区分出来。提示框有浅色底、类型图标和标题，可带折叠箭头 | 原话及来源用引用；例外、风险、建议用有语义的提示框。警告框优先显示明确的动作 |
| 表格 | 横列并排，标题行和标题列可使用独立的强调样式，列分别左、中、右对齐 | 同一组字段的比较、状态和小型参数表。数字通常右对齐，短状态可居中。长说明放到表格下方 |
| 字词强调 | 加粗加重字形，斜体倾斜，删除线穿过文本，下划线位于基线下。高亮用主题色或低透明度背景，字体色只影响所选文字 | 加粗突出结论或字段名；删除线连同替代内容表示改动。给「阻塞」「已核对」配语义颜色，同时保留文字状态 |
| 专用行内格式 | 行内代码用等宽字，键帽带边框，上下标改变字符位置 | 变量、短命令用行内代码，按键用键帽，化学式、幂次等短标记用上下标。一整条公式用 LaTeX |
| 围栏代码、公式块和分割线 | 围栏代码采用等宽字体和语法配色。行内公式贴随文字，块公式独占区域。分割线是细横线 | 用正确语言围栏承载可复制命令；独立推导用块公式；只有明显的章节转场才用分割线 |
| 链接、脚注和块引用 | 链接可点击，脚注从正文指向相应说明，块链接能定位到笔记中的特定块 | 对反复引用的定义使用块 ID，来源和长注释用脚注，文档导航用库内链接 |
| 图片、文件和媒体 | 图片可单张显示或排成一行。音视频和 PDF 采用相应预览，其他文件可用嵌入卡片或文本链接 | 用真实附件。需要进行视觉对比时再并排。下载材料只需要访问入口时用链接 |
| Mermaid 和 Excalidraw | Mermaid 从代码围栏渲染图形，可回到源码调整。Excalidraw 嵌入显示真实画板的预览，图形可在独立画板内编辑 | 简短、可版本比较的流程用 Mermaid。需要自由摆放节点、手绘或拖动图形时用 Excalidraw |

样式颜色、间距和字体受当前 Obsidian 主题、窗口宽度及插件设置影响。使用语义层级、文本标签和主题兼容色，避免用字号或空白硬凑布局。

## 按任务组合

- **快速记录**。以一个结论段落加几个任务项收尾。只有任务旁边必须带多段资料时才创建父子块，少量顺序用一个普通有序列表。
- **学习或技术笔记**。定义放正文，术语对照放表格，命令放围栏。把提醒留在实际执行步骤附近。需要复用定义时添加一个可跳转的块 ID。
- **计划或手册**。H2 负责阶段导航，H5 负责短局部说明。每阶段的验收条件在折叠外，把原始日志、对照表和操作步骤归到对应的可折叠父项下。
- **实验前后对照**。并排两张是真实结果的图，下面用短列表解释观察条件。表里的数据单位写进列标题，状态同时用文字表示。需要手动调整流程图时附真实画板。

## 同一笔记的两种交付

[基础稿](../assets/example-draft.md)用普通 Markdown 写出学习流程、产物和验收；[增强稿](../assets/example-note.md)把同一内容增加可折叠的父子步骤、编号章节、双色状态、独立的提示框、Mermaid 和可编辑画板预览。展开「学习流程」可以看到同一父块下的正文、引用、表格和 JavaScript。核验标准放在折叠外。

让已有草稿更清晰时，先选出阅读困难的那一节，保留正文和有效链接。逐项增加有清楚作用的格式。给原本简洁的 Markdown 模板新增样式时，只交付所需的增强段落或编辑差异；用户要求完整文件时再输出全篇。

## 编辑界面与文件分工

编辑界面可用块手柄移动父子组、用工具栏与斜杠菜单插入内容、用右侧大纲跳转；有父子层级时可显示折叠和缩进引导线。表格的标题、对齐和单元格内容可随文件携带。自动保存、查找替换、演示模式、导出、工具栏位置和复制 AI 引用属于操作或视图。生成笔记时用[保存格式](format.md)表达文档内容。
